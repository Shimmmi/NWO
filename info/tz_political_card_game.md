# ТЗ: «WORLD ORDER» — Политическая сатирическая карточная игра
**Версия:** 2.0 (браузер, мультиплеер)  
**Дата:** Июнь 2026

---

## 1. КОНЦЕПЦИЯ И ТЕМАТИКА

### 1.1 Общая идея

«World Order» — браузерная карточная игра 1v1 в жанре TCG с элементами файтинга. Игроки выбирают политика-бойца из реального мира (или гротескную пародию на него), строят колоду из его политических «способностей» и сражаются с оппонентом. Игра выдержана в духе политической карикатуры: гротескные иллюстрации, саркастические тексты, абсурдные эффекты.

### 1.2 Тематика вместо элементов

Вместо стихий (огонь, вода, земля) используется система **«Стран/Блоков»**:

| Страна/Блок | Игровой стиль | Цветовая идентификация |
|---|---|---|
| 🇺🇸 США | Агрессия, санкции, «бомбардировки твитами» | Красно-синий |
| 🇷🇺 Россия | Контроль, дезинформация, жёсткая защита | Красно-золотой |
| 🇨🇳 Китай | Экономика, долгосрочные эффекты, масштаб | Красно-жёлтый |
| 🇪🇺 Евросоюз | Бюрократия, дебаффы, «бесконечные переговоры» | Синий |
| 🇬🇧 Великобритания | Хаос, Brexit-механики, самосаботаж | Пурпурный |
| 🇰🇵 Северная Корея | Непредсказуемость, ядерный блеф | Серый |
| 🌐 Глобалисты | Поддержка союзников, международные механики | Зелёный |

**Совместимость карт:** Карты своей страны дают бонус к силе персонажа. Карты «союзных» стран работают в полную силу. Карты «враждебных» стран работают с пенальти или вовсе недоступны.

## 2. ИГРОВЫЕ СУЩНОСТИ

### 2.1 Персонаж (Fighter Card)

Каждый персонаж — пародия на реального политика или архетип. Представлен 2D-иллюстрацией (стиль политической карикатуры) на фоне страны.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `name` | string | Имя персонажа (пр.: «Дональд Рампф») |
| `country` | enum | Страна/блок принадлежности |
| `title` | string | Политический титул (пр.: «Величайший президент в истории») |
| `forms` | Form[3] | Три формы персонажа (см. 2.1.1) |
| `hp` | int | Здоровье (уникально для каждой формы) |
| `armor` | int | Броня |
| `energy_start` | int | Начальное значение энергии |
| `power` | int | Сила (множитель эффектов карт) |
| `speed` | int | Скорость (определяет приоритет в раунде боя) |
| `charges` | int | Заряды для уникальных способностей |
| `passive` | Ability | Пассивная способность (всегда активна) |
| `unique_abilities` | Ability[3] | Три уникальные способности фазы способностей |
| `deck_archetype` | string | Стартовая колода / стиль игры |

#### 2.1.1 Система форм (Evolution)

Каждый персонаж имеет **3 формы**, переключение происходит при падении HP до 0:

- **Форма 1** — «Политик на взлёте». Умеренные параметры.
- **Форма 2** — «Загнанный в угол». Усиленные атаки, изменённые способности.
- **Форма 3 (Финальная)** — «Абсолютная власть / Крах системы». Максимальная сила. Потеря HP в этой форме = поражение.

При смене формы: HP восстанавливается до значения новой формы, заряды обнуляются и восстанавливаются, визуально персонаж меняет облик (анимация трансформации).

#### 2.1.2 Пример персонажа — «Дональд Рампф»

```
Страна: 🇺🇸 США
Титул: «Самый богатый президент в истории (по его словам)»
Стиль: Агрессия, санкции, медийный контроль

Форма 1 — «The Candidate»: HP 30, Броня 0, Сила 3, Скорость 2
Форма 2 — «The President»: HP 25, Броня 5, Сила 5, Скорость 2
Форма 3 — «The Meme»: HP 20, Броня 10, Сила 7, Скорость 1

Уникальные способности:
1. «Твит в 3 ночи» (1 заряд) — Наносит 4 урона и накладывает «Медийный скандал» на 2 хода.
2. «Введём санкции» (2 заряда) — Блокирует одну карту оппонента на следующий раунд.
3. «Построить стену» (3 заряда) — Добавляет 15 брони. Противник не может использовать карты «Мигранты» и «Союзники».

Пассивка: «Fake News» — Раз в ход, если оппонент разыграл карту с уроном >5, бросается монета.
  Орёл: урон снижается вдвое.
  Решка: урон стандартный.

Колода: «Великая Америка» — карты санкций, твитов, тарифов, союзников-НАТО.
```

### 2.2 Карта Способности (Ability Card)

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `id` | uuid | Уникальный идентификатор |
| `name` | string | Название (пр.: «Тарифная война») |
| `country` | enum | Принадлежность к стране |
| `energy_cost` | int | Стоимость энергии |
| `speed` | int | Скорость карты (суммируется со скоростью персонажа) |
| `effects` | Effect[] | Массив эффектов карты |
| `flavor_text` | string | Художественный / саркастический текст |
| `rarity` | enum | Common / Rare / Epic / Legendary |
| `visual_type` | enum | attack / buff / debuff / control / special |

**Структура Effect:**

```typescript
interface Effect {
  type: EffectType;       // damage | heal | armor | buff | debuff | control | draw | special
  target: TargetType;     // self | opponent | both | all_cards
  value: number;          // int: базовое значение
  scaling: ScalingType;   // none | power | speed | charges
  duration?: number;      // ходы (null = постоянно)
  condition?: string;     // условие срабатывания
  flavor_param?: string;  // строковый параметр для отображения в описании
}
```

#### 2.2.1 Примеры карт (США)

**«Тарифная война»** (Common, Стоимость: 2, Скорость: 1)  
Нанести оппоненту [power×2] экономического урона. На следующий ход карты оппонента стоимостью 1-2 энергии стоят на 1 дороже.  
*«Мы просто выровняем правила игры. Доверяйте мне.»*

**«Выслать мигрантов»** (Rare, Стоимость: 3, Скорость: 0)  
Убрать из руки оппонента случайную карту страны, отличной от его персонажа. Получить 2 брони за каждую удалённую карту.  
*«Красивые люди, но пусть уходят.»*

**«Ядерный твит»** (Epic, Стоимость: 4, Скорость: 3)  
Нанести [power×4] урона. Если оппонент не успел сыграть свою карту в этом раунде (меньшая скорость) — дополнительно ошеломить на 1 ход.  
*«Моя кнопка больше.»*

**«Импичмент»** (Legendary, Стоимость: 6, Скорость: -1)  
Сбросить все карты с руки оппонента. Нанести по [5] урона за каждую сброшенную карту. Перемешать их в колоду.  
*«Охота на ведьм завершена. Ведьмы победили.»*

## 3. ФАЗЫ ХОДА (без изменений, адаптировано к теме)

### Фаза 1 — Восстановление («Ежегодное обращение к нации»)
- Каждый персонаж восстанавливает всю энергию.
- Максимальная энергия +1.
- Заканчиваются некоторые эффекты (см. Фаза 5).

### Фаза 2 — Добор карт («Брифинг»)
- Каждый игрок добирает карты до установленного лимита руки (по умолчанию: 5).
- Если колода пуста — игрок получает [2] урона за каждую недоборанную карту (штраф «политический кризис»).

### Фаза 3 — Фаза способностей («Закрытое заседание»)
- Игроки поочерёдно активируют уникальные способности персонажей, тратя заряды.
- Очерёдность чередуется каждый ход.
- Заряды не восстанавливаются автоматически (только через карты или смену формы).

### Фаза 4 — Фаза боя («Саммит»)
- Делится на раунды.
- Каждый раунд: игроки одновременно выкладывают по одной карте (закрыто) → карты открываются → определяется порядок по скорости (speed_card + speed_character) → применяются эффекты.
- Раунд продолжается, пока у обоих игроков есть возможность играть карты (энергия / карты в руке).
- Если оба пасуют — фаза боя завершается.

### Фаза 5 — Окончание хода («Перерыв на рекламу»)
- Уменьшение счётчиков длительных эффектов.
- Эффекты с duration=1 снимаются.
- Синхронизация состояния на сервере.

## 4. СИСТЕМА КОЛОД (TCG)

### 4.1 Правила колоды

- Размер колоды: 20–30 карт.
- Максимум 2 копии одной карты (3 для Common).
- Карты привязаны к стране персонажа + «нейтральные» карты (Глобалисты).
- У каждого персонажа есть предустановленная стартовая колода (для новых игроков).

### 4.2 Построитель колод (Deck Builder)

- Коллекция карт хранится в профиле игрока (БД).
- Визуальный drag-and-drop интерфейс в браузере.
- Фильтрация по стране, редкости, стоимости, типу эффекта.
- Валидация колоды в реальном времени (количество карт, лимиты).
- Сохранение нескольких колод на одного персонажа.

### 4.3 Получение карт

- Победа в матче → опыт → уровни → пакеты карт.
- Ежедневные задания (пр.: «Выиграй 2 матча за США»).
- Внутриигровая валюта (без pay-to-win: только косметика).
- Крафт: 4 дубликата одной редкости → 1 карта выше редкостью.

## 6. АРХИТЕКТУРА МУЛЬТИПЛЕЕРА

### 6.1 Аутентификация и профиль

**Регистрация / Вход:**
- Email + пароль (bcrypt хэширование)
- OAuth: Google, Discord (опционально)
- JWT access token (15 мин) + refresh token (30 дней) в httpOnly cookie

**Профиль игрока (БД):**
```
User: id, username, email, password_hash, avatar, created_at
PlayerProfile: user_id, rating, wins, losses, level, xp, currency
Collection: user_id, card_id, count
Deck: id, user_id, name, character_id, cards[]
```

### 6.2 Матчмейкинг

**Два режима:**

1. **Рандомный матч** — игрок встаёт в очередь с выбранной колодой и персонажем. Сервер подбирает оппонента с близким рейтингом (±200 ELO, таймаут расширяет диапазон).

2. **Прямой вызов** — игрок создаёт лобби, получает 6-символьный инвайт-код, передаёт другу. Друг вводит код и попадает в лобби.

**Матчмейкинг-сервер (Redis):**
```
matchmaking_queue: sorted set по рейтингу
lobby:{code}: hash с состоянием лобби
game:{gameId}: состояние активного матча
```

### 6.3 Игровая сессия (Game State Machine)

Вся игровая логика выполняется **на сервере** (авторитарная модель). Клиент только отправляет действия и получает обновления состояния.

```typescript
// Игровые события (Socket.IO events)
CLIENT → SERVER:
  'action:play_card'   { cardId, targetId? }
  'action:use_ability' { abilityIndex }
  'action:pass_phase'  {}
  'action:pass_round'  {}

SERVER → CLIENT:
  'state:update'       { gameState }
  'state:phase_change' { phase, activePlayer }
  'state:round_resolve'{ events: AnimationEvent[] }
  'state:game_over'    { winner, stats }
```

**Состояние игры (GameState):**
```typescript
interface GameState {
  gameId: string;
  turn: number;
  phase: Phase;
  activePlayer: PlayerSlot;  // 'p1' | 'p2'
  abilityOrder: PlayerSlot;  // кто первый в фазе способностей
  players: {
    p1: PlayerState;
    p2: PlayerState;
  };
  roundLog: RoundEvent[];
}

interface PlayerState {
  userId: string;
  character: CharacterState;
  hand: Card[];         // p1 видит свою руку полностью, p2 — только количество
  deckCount: number;
  discardTop?: Card;
  pendingCard?: Card;   // выложенная, но ещё не открытая карта
  hasPassed: boolean;
}
```

### 6.4 Античит

- Валидация всех действий на сервере (достаточно энергии, карта в руке, верная фаза).
- Rate limiting на Socket.IO события.
- Таймер на ход (60 сек), автопас при истечении.
- Логирование всех матчей для replay.

## 8. БАЗА ДАННЫХ (PostgreSQL / Prisma)

```prisma
model User {
  id            String   @id @default(uuid())
  username      String   @unique
  email         String   @unique
  passwordHash  String
  createdAt     DateTime @default(now())
  profile       PlayerProfile?
  decks         Deck[]
  collection    CollectionItem[]
  matchesAsP1   Match[]  @relation("P1")
  matchesAsP2   Match[]  @relation("P2")
}

model PlayerProfile {
  userId    String @id
  user      User   @relation(fields: [userId], references: [id])
  rating    Int    @default(1000)
  wins      Int    @default(0)
  losses    Int    @default(0)
  level     Int    @default(1)
  xp        Int    @default(0)
  currency  Int    @default(0)
}

model Card {
  id          String      @id @default(uuid())
  name        String
  country     String
  energyCost  Int
  speed       Int
  rarity      String
  effects     Json
  flavorText  String
  visualType  String
  collectionItems CollectionItem[]
}

model CollectionItem {
  id      String @id @default(uuid())
  userId  String
  cardId  String
  count   Int    @default(1)
  user    User   @relation(fields: [userId], references: [id])
  card    Card   @relation(fields: [cardId], references: [id])
  @@unique([userId, cardId])
}

model Deck {
  id          String   @id @default(uuid())
  userId      String
  characterId String
  name        String
  cards       Json     // [{cardId, count}]
  createdAt   DateTime @default(now())
  user        User     @relation(fields: [userId], references: [id])
}

model Match {
  id         String   @id @default(uuid())
  p1Id       String
  p2Id       String
  winnerId   String?
  replayLog  Json
  ratingDelta Json    // {p1: +15, p2: -15}
  startedAt  DateTime @default(now())
  endedAt    DateTime?
  p1         User     @relation("P1", fields: [p1Id], references: [id])
  p2         User     @relation("P2", fields: [p2Id], references: [id])
}
```

## 10. ОТЛИЧИЯ ОТ ОРИГИНАЛЬНОГО ТЗ

|---|---|---|
